# 🧮 Calculator Web Application

A responsive and interactive calculator web application built from scratch using **HTML5, CSS3, and JavaScript**.

The application supports basic arithmetic operations, keyboard input, delete/reset functionality, and theme switching with a clean and responsive user interface.

## 🚀 Live Demo

[View Live Demo](https://ahmed-khalaf1223.github.io/calculator/)

## 📸 Preview

![Calculator Preview](./preview.png)

## ✨ Features

* Fully responsive design
* Basic arithmetic operations
* Dark and light theme switching
* Keyboard support
* Delete and reset functionality
* Decimal number support
* Prevention of duplicate decimal points
* Interactive button effects
* Clean and modern UI

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript (ES6+)

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/Ahmed-Khalaf1223/calculator.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional dependencies or installation steps are required.
